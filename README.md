# HEMC-Hospital-Equipment-Maintenance-Control
O HEMC é uma plataforma web para gestão e controle de manutenções preventivas e corretivas de equipamentos médico-hospitalares. O sistema centraliza chamados e processos para otimizar a organização hospitalar.
